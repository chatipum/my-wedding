# จัดแขกลงโต๊ะ — design (สั้น) · ปรับผัง 2026-11-23

| หัวข้อ | สรุป |
|---|---|
| เป้าหมาย | วางแผนที่นั่งเองล่วงหน้า ดูเองบนจอ — ไม่ใช้หน้างาน ไม่พิมพ์ส่งใคร |
| ผัง | ตาม `docs/เวที4.png`: เวทีอยู่บน ทางเดินกลาง · 9 แถว × 6 คอลัมน์ · ซ้ายเจ้าสาว 26 โต๊ะ ขวาเจ้าบ่าว 24 โต๊ะกลม + โต๊ะยาว · แถว 9 คอลัมน์ 1 และ 6 ว่าง · ชื่อกลุ่มที่เขียนในรูปไม่ใช้ |
| โต๊ะยาว | "ประธานและครอบครัว" ฝั่งเจ้าบ่าว คอลัมน์ 4 กินพื้นที่แถว 1–2 · จัดแขกเป็นโต๊ะเดียว 16 ที่ · นับเป็น 2 โต๊ะในยอดรวม |
| ที่นั่ง | โต๊ะกลมละ 8 · รวม 52 โต๊ะ 416 ที่ = เพดานแขก `GUEST_CAPACITY` ใน `src/lib/break-even.ts` (ปรับจาก 400) |
| ชื่อโต๊ะ | ไม่ได้ตั้งไว้ล่วงหน้า แสดงชื่อกลุ่มของแขกที่นั่งอยู่ (ช่อง `group`) ถ้าหลายกลุ่มก็โชว์ทุกกลุ่ม |
| เก้าอี้ | วางรอบโต๊ะตามจำนวนที่นั่ง · แขกหลักแสดงชื่อย่อ ผู้ติดตามแสดงชื่อย่อต่อด้วยลำดับ (`สช` `สช2` `สช3`) · ตัวที่ยังไม่มีคนเป็นเก้าอี้ว่าง · ส่วนที่เกินเป็นสีแดง |
| ชื่อย่อ | เพิ่มช่อง "ชื่อย่อ" ในฟอร์มแขก · ถ้าว่างใช้ 2 ตัวอักษรแรกของชื่อ |
| นับที่นั่ง | แขก 1 ราย = 1 + ผู้ติดตามที่ยืนยันแล้ว · ยังไม่ยืนยัน = 1 — กฎเดียวกับ `src/lib/totals.ts` |
| หน่วยที่จัด | ยกทั้งกลุ่ม (แขก + ผู้ติดตาม) นั่งโต๊ะเดียว |
| วิธีใช้ | คลิกโต๊ะบนผัง → แผงข้างโชว์คนที่นั่งโต๊ะนั้น [เอาออก] + แขกฝั่งเดียวกันที่ยังไม่มีโต๊ะ ค้นชื่อได้ [ใส่] |
| สีโต๊ะ | ว่าง / มีคน / เต็มพอดี / เกิน 8 (แดง) — เกินยังใส่ได้ แค่เตือน |
| สรุปหัวหน้า | จัดแล้วกี่คน / 416 ที่ · ยังไม่มีโต๊ะกี่ราย · เกินกี่โต๊ะ |
| ข้อมูล | ตำแหน่งโต๊ะของแขกเป็นเลขช่องตามผังใหม่ · เปลี่ยนผังแล้วล้างโต๊ะเดิมทุกคนด้วย migration (ผู้ใช้รันเอง) · ผังและจำนวนที่นั่งเป็นค่าคงที่ในโค้ด |
| เมนู | ลิงก์ "จัดโต๊ะ" ใน `src/components/nav.tsx` |
| มือถือ | ผังบน แผงล่าง |

## ทางที่พิจารณา

| ทาง | trade-off | ผล |
|---|---|---|
| a คลิกโต๊ะแล้วเลือกแขก | เห็นผัง ใช้ได้ทั้งคอม/มือถือ ไม่ต้องลงไลบรารี | **เลือก** (ผู้ใช้ลองเดโมแล้ว) |
| b ลากชื่อไปวาง | รู้สึกดีสุด แต่มือถือต้องลงไลบรารีลากวาง โค้ดเยอะกว่า | ไม่เลือก |
| c dropdown ในตารางแขก | โค้ดน้อยสุด แต่ไม่เห็นผัง เรียกโต๊ะไม่มีชื่อยาก | ไม่เลือก |

## ไม่ทำ

ตั้งชื่อ/เลขโต๊ะเอง · ลากวาง · พิมพ์ผัง · แยกผู้ติดตามคนละโต๊ะ · หน้าค้นโต๊ะวันงาน · จัดอัตโนมัติ · ช่องชื่อย่อในนำเข้า/ส่งออกรายชื่อแขก

## ตัดสินโดย agent (ผู้ใช้ไม่ได้แย้ง)

| เรื่อง | ตัดสิน |
|---|---|
| แขกตอบว่าไม่มา | ซ่อนจากรายชื่อ ไม่นับที่นั่ง แต่ไม่ล้างโต๊ะที่จัดไว้ เผื่อเปลี่ยนใจ |
| แขกถูกแก้ฝั่งหลังจัด จนผิดฝั่งโต๊ะ | ยังโชว์ในโต๊ะเดิม ไม่ย้ายให้เอง |
| ตัวกรองฝั่งในรายชื่อ | ไม่มี — โต๊ะกำหนดฝั่งให้แล้ว |
